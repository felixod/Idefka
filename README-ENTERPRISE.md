# Idefka Enterprise — форк для ИТ-компании холдинга

Форк [NEVAsick/Idefka](https://github.com/NEVAsick/Idefka), доработанный под задачи операционной
модели ИТ-компании: оргструктура, прогноз стоимости обслуживания и генерация оргдокументов.
Форк сделан с разрешения автора оригинального проекта.

## Что добавлено

- **Раздел «Оргструктура и стоимость…»** в меню «Файл» (для IDEF0-моделей):
  - сводка: штат, ФОТ/мес, ФОТ/год с социальными взносами, цена обращения L1, стоимость поддержки объекта;
  - таблицы по отделам и ролям с привязкой к работам IDEF0 (номера работ видны рядом);
  - редактируемые параметры: месяцы, ставка взносов, обращений/мес, пользователей на объекте;
  - экспорт: **смета ФОТ (CSV для Excel)** и **Положения об отделах + должностные инструкции (Markdown)**,
    сгенерированные из модели (функции отдела и обязанности роли = работы IDEF0, KPI — из примечаний работ).
- **Формат файла**: опциональное поле `org` (отделы, роли, оклады, FTE, привязка к работам, параметры расчёта).
  Поле необязательное: файлы без `org` открываются как раньше, файлы с `org` читаются и исходной Idefka
  (неизвестное поле игнорируется). Версия формата не менялась — совместимость сохранена.
- Брендинг: логотипы компании (светлый/белый/знак) и фирменные цвета темы; название проекта сохранено оригинальным (Idefka).
- CI: GitHub Actions собирает проект и публикует GitHub Pages.

## Структура org в .idef

```jsonc
{
  "org": {
    "params": { "months": 12, "socialRate": 0.302, "ticketsPerMonth": 1500,
                "usersPerSite": 350, "ticketsPerUserPerMonth": 0.8, "sites": 8 },
    "departments": [
      { "id": "SD", "name": "Служба сервис-деска (L1)", "mission": "…",
        "roles": [
          { "id": "l1", "name": "Аналитик сервис-деска (L1)", "grade": "Middle",
            "salaryMin": 70000, "salaryMax": 110000, "fte": 8,
            "works": ["A11", "w1"], "note": "" }
        ] }
    ]
  }
}
```

`works` — id работ IDEF0 (уникальные id блоков в диаграммах модели). Цена обращения считается по
отделам, чей `id` начинается с `SD`.
